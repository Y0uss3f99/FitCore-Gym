# 💪 FitCore Gym — Fitness Landing Page

FitCore Gym is a fitness website landing page designed to showcase a premium gym experience. It highlights the gym's facilities, professional trainers, fitness programs, member testimonials, and membership options through a structured and engaging user interface.

## ✨ Features

- 🏋️ **Hero Section:** An introduction to FitCore Gym with prominent call-to-action buttons.
- ⚡ **Why Choose Us:** Highlights premium equipment, expert trainers, and flexible opening hours.
- 🧘 **Fitness Services:** Showcases group classes, nutrition guidance, and recovery facilities.
- ⭐ **Member Testimonials:** Displays customer experiences and fitness success stories.
- 📊 **Gym Statistics:** Highlights active members, trainers, group classes, and opening hours.
- 📝 **Membership Registration Form:** Includes personal details, email, phone number, membership plans, and fitness goals.
- 🔗 **Footer Navigation:** Provides quick links, contact information, social media links, and policy sections.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive web design principles

## 🎯 Project Goals

This project demonstrates my front-end development skills in building structured web pages, creating reusable layout patterns, designing forms, organizing content into sections, and developing visually engaging user interfaces using HTML and CSS.
